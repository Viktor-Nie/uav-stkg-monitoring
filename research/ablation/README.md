# Ablation evidence for manuscript v33

Default reproduction is offline: run `python -B build_ablation_artifacts.py` in this directory. It reads frozen CSV inputs and 20 retained structured model outputs, recomputes 380 item results and historical rescoring, redraws the three figures, and performs no network or model call. Run `python -B -m unittest discover -s . -p test_numeric_text_guard.py -v` for the numeric conflict checks, including all 24 original configurations.

Dependencies used for plots and scoring: Python with pandas 2.3.3, numpy 2.3.5, matplotlib 3.10.6. These were already installed on the execution host; no dependency was installed for this experiment. Macro F1 is computed directly over the fixed two scope classes with zero for absent classes. Dependency-free candidate and numeric gates are in `ablation_scoring.py` and `numeric_text_guard.py`.

The new portable entry point is `validate_candidate.py INPUT.json`. Its input includes `original_text`, the candidate fields, the frozen `bindings`, and the allowed signal/template `admissible_pairs`. It actually calls the numeric text guard first and STKG compatibility second; a numeric conflict prevents the STKG call and returns no bound values. It preserves all 24 original valid configurations. This is a new explicitly invoked pre-binding path, not an automatic change to the historical model runner or replay pipeline.

New model inference is a separate opt-in command: `python -B run_fair_language_ablation.py --mode run --model gpt-5.5 --output-dir NEW_DIRECTORY`. The output directory must not already exist. This command may use account quota; it never overwrites the retained experiment. It sends only the 19 public-derived Chinese sentences, anonymous IDs, and the task protocol, using fresh empty temporary working directories, an empty MCP configuration, disabled tools, and identical output JSON constraints. A model availability check can be requested separately with `--mode availability`. The exact serving snapshot was not returned by Codex CLI 0.145.0; requested model, settings, raw structured outputs, times, usage and failures are retained.

The experiment contains 19 distinct source-derived text items, four prompt conditions, and five independent contexts per condition: 20 completed processes and 380 item opportunities. Repeated contexts do not create 380 independent requirements. The source-reviewed text reference has five upper-bound height items and fourteen unsupported items. It corrects the two PX4 detection/recovery assignments and the groundspeed/3D-speed mismatch, without overwriting the historical reference or scores. Height-frame compatibility remains unresolved; these external descriptors do not instantiate a verified physical monitor configuration. There is no reference-positive bounded-response item in the reviewed set, so effects on response-role generation are unmeasured.

Removing the explicit role map leaves role names within the skeleton when that skeleton is supplied; this is an intentional test of redundant information, not a claim that all role information vanished. Removing skeletons causes canonical serialization failures while tuple selection remains high. The gate tests compatibility of descriptors, not equivalence to the text. The 29 manually constructed semantic challenges are separate from the 380 model outputs and do not increase the language-corpus denominator.

`public_calls` retains only requests, structured outputs and relevant receipts. Original complete CLI streams and session identifiers remain in the local private experiment directory and are not part of this public preparation. The source review is computational. Anonymous historical decisions are supplied in data/annotation; the revised nineteen-item reference has not yet been reviewed by those classmates. File hashes do not independently authenticate the reported process. Original public snapshots are identified by URL and hash in the review ledger and are not duplicated here.
