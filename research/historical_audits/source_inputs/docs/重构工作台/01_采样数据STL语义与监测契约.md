# 采样数据 STL 语义与监测契约（v2 设计基线）

更新日期：2026-08-10。本文档定义 v2 重构后允许写入论文的方法边界。它不是对连续物理轨迹或飞控软件正确性的证明；它只定义**带时间戳、可观测状态轨迹上的采样点监测**。监测器、复杂度分析和受限语义交集上的差分测试已实现；其适用边界仍必须按本文档执行，不能反向表述为连续时间或飞控正确性证明。

## 1. 适用对象与输入契约

一条轨迹记为：

`σ = ((t_0, x_0), ..., (t_n, x_n))`，其中 `t_i ∈ R_≥0` 且 `x_i` 是时刻 `t_i` 的可观测信号向量。

每个信号都必须有元数据：`signal_id`、物理量、单位、坐标系/参考系、原始字段、适用机型/固件/飞行模式、提取脚本版本。没有这些元数据的字段不能被包装成可解释的安全规约输入。

对一次实验，声明采样契约 `C = (Δ, η, g_max, ε_t)`：

- `Δ`：名义采样周期；
- `η`：允许的相对抖动；每个相邻间隔应属于 `[Δ(1-η), Δ(1+η)]`；
- `g_max`：最大允许缺测间隔；
- `ε_t`：时间戳比较容差。

轨迹至少应含两个采样点，才可能观察到一个采样间隔并建立所声明的采样周期。它只有在时间戳和所有声明信号均有限、时间戳严格递增、无超出 `g_max` 的间隔、无超出声明抖动范围的间隔时，才可用于本文的严格 sampled-point 语义。空轨迹或单点轨迹均输出 `RejectedInput`；契约不通过时：**拒绝作为严格语义证据，不插值、不补点、不把离散日志伪装为连续轨迹。**

当前执行审计：`specification/v2/audit_current_sampled_traces.py`；机器可读结果：`specification/v2/results/sampling_contract_audit.json`。

|---|---|---|---|
| `real_px4_observable_trace.csv` | `Δ=0.05 s, η=5%, g_max=0.10 s` | 1,220 点，全部通过 | 可作为当前严格 sampled-point 回放案例 |
| `external_px4_pyulog_observable_trace.csv` | `Δ=0.02 s, η=25%, g_max=0.08 s` | 3,268 点；12 个抖动违例、1 个缺测间隔违例 | 仅 ULog 适配/接口兼容性案例，不用于严格语义结论 |

该结论只说明日志是否满足输入契约；不说明飞行是否安全，也不等价于真实飞行环境的统计泛化结论。

### 1.1 独立的原生事件时间观测契约

为处理公开 ULog 中不同 topic 的非等周期记录，v2 另定义了**原生单信号事件时间语义**，且它不替代上面的严格 fixed-rate sampled-point 语义。对一条单信号轨迹，仅声明 `C_event=(g_obs, ε_t)`：时间戳和值必须有限、时间戳严格递增、任意相邻原始观测间隔不超过 `g_obs`；不声明名义周期，也不做抖动判定。每条公式只在其所绑定信号的**原始观测时刻**求值；不同 topic 禁止精确或邻近对齐、插值、补点、重采样和 hold-last-value 填充。空轨迹、单点、非有限值、非递增时间戳或超观察间隔仍输出 `RejectedInput`。

这不是把异步日志转换成同步多变量轨迹的许可。当前图谱中的每个公式都只读取一个标量信号，因而可以按信号分别回放；若未来扩展到多信号谓词，必须另行定义并验证跨 topic 的观测/未知值语义。对 Flight Review 日志，`g_obs=0.10 s` 仅是该离线原生观测实验的完整性门槛，不是飞控采样要求、传感器陈旧度保证或安全参数。

## 2. 受支持的受限规约片段

令 `y` 为一个已绑定、单位一致的标量可观测信号。`θ`、`u`、`r`、`d`、`τ` 分别表示上界、触发上界、恢复阈值、恢复期限和恢复持续时间；参数由显式 `ParameterBinding` 提供，不从“同一信号关联的候选阈值”中随意选择。

v2 仅支持下列片段：

```text
φ_inv  ::= G (y ≤ θ)
φ_resp ::= G ((y > u) → F_[0,d] Recover(y, r, τ))
```

其中 `Recover(y, r, τ)` 在采样点语义下表示：存在一个起始采样点 `j` 和一个终止采样点 `k ≥ j`，满足：

1. `0 ≤ t_j - t_i` 且 `t_k - t_i ≤ d`；
2. `t_k - t_j ≥ τ`；
3. 对所有已观测采样点 `l ∈ [j,k]`，`y_l ≤ r + ε_y`。

`ε_y` 是单位与信号绑定的数值比较容差，不能使用无量纲的全局常数。若 `τ=0`，恢复条件退化为一个满足恢复阈值的采样点。v1 代码仅实现了 `τ=0`；v2 监测器已实现正的持续恢复时间，并以单元测试覆盖其状态转换。RTAMT 差分仍只覆盖双方共享的 `τ=0` 子集，不能把该对照外推为正持续时间的第三方验证。

## 3. 有限轨迹三值判定

所有判定只针对观测到的有限前缀 `σ[0:n]`，使用 `Satisfied`、`Violated`、`Inconclusive` 三值，而不是把末尾尚未到期的义务误报为通过或失败。

### 3.1 上界不变式

对 `φ_inv`：若所有 `i ∈ [0,n]` 均满足 `y_i ≤ θ + ε_y`，输出 `Satisfied`；一旦存在 `y_i > θ + ε_y`，立即输出 `Violated`。该定义仅说明**所有已采样点**未越界；对两个采样点之间是否越界不作推断。

### 3.2 限时恢复

本文 v2 采用**电平触发**，以和现有原型的义务列表语义保持可追溯：每一个满足 `y_i > u + ε_y` 的采样点都创建一个触发和一项义务 `o_i=(t_i, t_i+d)`；它们不是自动合并为一个“故障事件”。

对每项义务：

- 在期限内出现满足 `Recover` 的采样段，则该义务为 `Satisfied`；
- 若截至当前最后时间 `t_n` 已有 `t_n > t_i+d`，但没有满足恢复段，则该义务为 `Violated`；
- 若尚未到期且没有恢复段，则该义务为 `Inconclusive`。

整个规约的输出按优先级聚合：任一义务 `Violated` 则为 `Violated`；没有违反但至少一项义务 `Inconclusive` 则为 `Inconclusive`；否则为 `Satisfied`。这要求论文、状态图、实现和统计表分别报告：越界采样点数、触发数、义务数、已恢复义务数、到期违反义务数和未决义务数。

若后续希望以**边沿触发**合并连续越界区间，必须作为另一种明确的语义和实验条件，不能与本电平触发结果混报。

## 4. 定量鲁棒度（受限、采样点）

对原子谓词定义观测鲁棒度：

`ρ_i(y ≤ a) = a - y_i`，正值表示在采样点上有裕度，负值表示越界。

对离散时间索引集合 `J_i(d)={j | i≤j≤n, 0≤t_j-t_i≤d}`，定义：

`ρ_i(F_[0,d] ψ) = max_{j∈J_i(d)} ρ_j(ψ)`；

`ρ_i(G ψ) = min_{0≤j≤n} ρ_j(ψ)`。

恢复持续时间 `τ>0` 的三值义务判定已由 v2 状态机实现；本文仍不报告其复合鲁棒度数值，因为 RTAMT 对照不覆盖正持续时间和末尾不确定性。任何鲁棒度数值都仅针对观测采样点，不能外推为连续时间最小安全裕度。

## 5. 监测器实现与证明的交付要求

在本契约之下，监测器被定义为状态转换系统：状态至少包含当前时间、已创建且未终结的义务集合、每项义务的期限/恢复持续状态和输出 verdict；转换写明输入、守卫、状态更新和输出。已交付：

1. 给出上界不变式与限时恢复模板相对上述有限轨迹语义的正确性证明；
2. 给出每采样点的时间/空间复杂度，并说明义务数量的最坏情况；
3. 用独立监测实现做差分测试，覆盖随机、边界、末尾未决、相等阈值、相等期限、抖动和缺测拒绝；
4. 将 v1 的 35 条人工 oracle 保留为回归测试，但不作为独立正确性证据。

## 6. 当前可写与不可写的结论

现在可以写：主 20 Hz 回放日志经显式输入审计，满足当前声明的 sampled-point 监测前提；两份不同公开来源的 ULog 均存在记录在案的严格 fixed-rate 时间契约违例，故不能作为该严格语义证据。独立 Flight Review 日志还可在另一份、明确标识的原生单信号事件时间语义下回放 15 个姿态/角速度公式；该结果不改变前述严格语义拒绝结论。

现在不能写：监测器已经对连续 UAV 动力学正确；可检出采样间的所有短脉冲；公开 ULog 已通过同一严格 20 Hz 语义验证；原生单信号事件时间回放等价于同步多信号监测或跨平台验证；HIL 参考阈值就是实际飞行安全边界；或受限片段之外的 STL 监测已得到形式化或第三方正确性证明。
