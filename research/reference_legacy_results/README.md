# Manuscript artifact identifiers

`manuscript_artifact_map.csv` covers identifiers in the supplementary source,
including recursively included generated fragments. A legacy identifier is not
an assertion that the original private directory exists in this repository.

Supplied files/directories resolve within the repository. Current reproduction
entries generate new outputs; use a new output directory. Entries requiring
external inputs use the exact versions and hashes in
`research/real_replay/SOURCE_INPUTS.md`. Manuscript layout assets are in the
separate editable LaTeX archive. Explicit private process records and the old
complete local inventory are not published or advertised as runnable results.

The primary offline command is `python reproduce.py --output NEW_DIRECTORY`.
It makes no model call, training run, or download. Optional full raw HIL and
four-source replay commands are documented in the root README.

`research/reference_legacy_results` contains retained aggregate scientific
results and decision-only projections. Run
`python research/reference_legacy_results/reproduce_auxiliary_rates.py --output NEW_DIRECTORY`
to check saved predictions against historical rate summaries, and
`python research/reference_legacy_results/plot_legacy_summaries.py --output NEW_DIRECTORY`
to redraw three historical summaries. These commands do not reconstruct
classifier features, retrain a model, or establish new external validation.

Superseded language figures retain old union-label F1 for provenance. They do
not replace the corrected fixed-three-class scores (character SVM 0.472,
keyword rule 0.348). Current ablation plots are regenerated by
`reproduce_ablation.py`. The nineteen revised language labels remain provisional
pending new independent human review.
